# Profe Lucía 🇪🇸

듣고 읽기는 되는데 말이 안 나오는 사람을 위한 **스페인어 말문 트기 회화 선생님** 앱.
설명은 한국어로, 대화는 스페인어로. 막히면 한국어로 말해도 됩니다.

**앱 주소:** https://jjhh120-blip.github.io/profesoralucia/

## 폰에 설치하기 (안드로이드)
1. 안드로이드 **크롬**으로 위 주소를 엽니다.
2. 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**를 누릅니다.
3. 앱을 열고 오른쪽 위 **설정**에 **Anthropic API 키**를 넣습니다 ([console.anthropic.com](https://console.anthropic.com)에서 발급).
4. **수업 시작하기** → 🎤를 누르고 말한 뒤 다시 누르면 보내집니다. 처음에 마이크 허용을 눌러 주세요.

## 기능
- 모드 6개: 자유 대화 · 롤플레이 · 한→스 순발력 · 쉐도잉 · 스토리텔링 · 복습
- 대화를 끊지 않는 교정 카드 (틀린 부분 → 자연스러운 문장 → 한국어 설명)
- 틀린 패턴과 배운 표현 자동 저장, 복습 모드에서 다시 출제
- 세션 리포트와 "말한 단어 수" 기록
- 기록 백업/불러오기 (설정 화면)

## 폰에서 바로 고치기
1. Claude 앱(또는 claude.ai) → **Code** → 저장소 `jjhh120-blip/profesoralucia` 선택
2. "선생님이 말을 너무 길게 해" 같은 피드백을 그대로 말합니다.
3. Claude가 수정해서 `main`에 push하면 1~2분 뒤 앱에 반영됩니다. 설정 화면 하단의 버전 번호로 확인하세요.

## 개인정보
- API 키와 학습 기록은 **폰 브라우저 안에만** 저장되고 이 저장소에는 올라가지 않습니다.
- 대화 내용은 답변을 만들기 위해 Anthropic API로만 전송됩니다.
- 요금은 내 API 키 사용량에서 나갑니다. 비용을 줄이려면 설정에서 Haiku 5.5를 고르세요.
